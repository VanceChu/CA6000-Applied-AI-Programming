## 二、第一章监督学习与无监督学习

### 2.1 人工智能、机器学习与数据科学的定义

1. 人工智能（Artificial
   Intelligence）：具备像人类一样学习和推理能力的程序。
2. 机器学习（Machine Learning）：无需明确编程即可自主学习的算法。
3. 深度学习（Deep Learning）：机器学习的子集，利用人工神经网络从大规模数据中学习。
4. 数据科学（Data Science）：一门旨在从数据中提取价值的交叉学科，与人工智能、机器学习、深度学习存在重叠，其应用需结合特定领域知识，价值可通过预测模型、数据仪表盘或报告等形式呈现。
5. 监督/无监督学习：是数据科学的基础，支撑众多高级人工智能技术的发展。

### 2.2 机器学习算法分类

| 算法类型       | 核心特征                 | 具体算法
|

|----------------|--------------------------|--------------------------------------------------------------------------|

| 监督学习       | 基于带标签数据集，有明确输出目标
| 回归（线性回归等）、决策树、随机森林、K近邻（KNN）、逻辑回归、朴素贝叶斯、支持向量机（SVM）
|

| 无监督学习     | 基于无标签数据集，无明确输出目标

|

| 强化学习       | 通过奖励和惩罚机制进行学习   | 隐马尔可夫模型等
|

### 2.3 监督与无监督学习的重要性

1. 是数据科学家和人工智能工程师的必备知识，构成机器学习的基础。
2. 支撑多种高级人工智能技术的研发与应用。
3. 适用范围广，可解决金融、医疗、营销等多个领域的各类问题（如大数据降维、客户留存、欺诈识别、疾病诊断、推荐系统、市场预测等）。
4. 具有极强的现实意义，能为企业和科研机构的高层决策提供指导。
5. 跨行业灵活性高，可适配不同行业的差异化需求。

### 2.4 监督学习详解

#### 2.4.1 核心概述

监督学习基于包含特征X和标签目标Y的数据集，核心目标是构建数学模型，挖掘X与Y之间的关系。模型通过学习数据中的“正确示例”（真实标签），找到X到Y的最优映射关系，实现对未知数据的预测。

#### 2.4.2 典型应用场景

| 输入数据（X）       | 应用场景                 |

|----------------------|--------------------------|

| 邮件                 | 垃圾邮件过滤             |

| 音频                 | 语音识别                 |

| 英文文本             | 机器翻译（英译西等）     |

| 广告+用户信息        | 在线广告点击预测（0/1分类）
|

| 图像+雷达信息        | 自动驾驶汽车中其他车辆定位
|

| 手机图像             | 视觉检测（判断是否存在缺陷，0/1分类）
|

#### 2.4.3 核心算法

1. 线性回归（Linear Regression）

   - 核心公式：基础形式为y
     = mx + c，模型函数为fₙ,b
     = wx + b（w为直线斜率，b为y轴截距）。
   - 目标：找到最优参数w和b，构建拟合数据集的“最佳拟合线”，最小化预测值与实际值的误差。
   - 误差计算：通过代价函数（平均平方误差）评估，核心是最小化代价函数J(w,b)。
   - 示例：根据房屋面积（连续变量X）预测房屋价格（Y），回归直线可最小化实际房价数据点与直线的垂直距离误差。
2. 逻辑回归（Logistic Regression）

   - 与线性回归的区别：适用于分类问题，通过sigmoid函数将输出值映射到0-1区间，实现二分类预测。
   - 核心公式：p(x)
     = 1 / [1 + e^-(wx + b)]，通常以0.5为阈值，输出值大于0.5判定为类别1，小于0.5判定为类别0。
3. 分类算法示例（邮件分类）

   通过邮件中的单词数量（X轴）和垃圾邮件关键词数量（Y轴）构建模型：蓝色点代表非垃圾邮件，红色区域代表垃圾邮件，模型学习出区分两类数据的决策边界，准确率可达94.0%。
4. 金融欺诈识别

   难点：真实欺诈案例较少；解决方式：借助领域专家制定的欺诈规则生成合成标签和初始特征，以此为基础训练监督学习模型，体现人工经验的重要性。

### 2.5 无监督学习详解

#### 2.5.1 核心概述

无监督学习使用无标签数据，无需依赖真实标签Y，核心目标是挖掘数据中隐藏的模式、结构和内在特征，适用于大规模数据集的聚类、降维等复杂处理任务，可发现此前未被察觉的数据规律。

#### 2.5.2 典型应用：客户细分

企业通过客户细分实现个性化服务，指导营销和定价策略，细分参数分为四类：

1. 地理因素：国家、城市、邮政编码等。
2. 人口统计因素：年龄、性别、收入、职业等。
3. 行为因素：过往购买记录、消费峰值时段等。
4. 心理因素：性格特质、态度、信念等。

核心算法：聚类算法（将客户分组，实现精准运营）。

### 2.6 监督学习与无监督学习对比

| 对比维度       | 监督学习                 | 无监督学习               |

|----------------|--------------------------|--------------------------|

| 输入数据       | 带标签数据               | 无标签数据               |

| 反馈机制       | 有                       | 无                       |

| 数据分类依据   | 基于训练数据集的标签     | 基于数据自身的属性特征   |

| 细分类型       | 回归、分类               | 聚类、关联分析           |

| 核心用途       | 预测                     | 分析                     |

| K均值聚类、层次聚类、先验算法等
|

| 类别数量       | 已知类别数量             | 未知类别数量             |

### 2.7 模型评估与优化

#### 2.7.1 过拟合与欠拟合

- 欠拟合（高偏差）：模型过于简单，无法解释数据中的方差，预测效果差。
- 过拟合（高方差）：模型过度贴合训练数据，甚至拟合噪声，泛化能力弱。
- 合适拟合：模型既能捕捉数据的核心规律，又具备良好的泛化能力。

#### 2.7.2 评估方法

1. 数据集划分：将数据分为训练集（模型训练）、验证集（超参数调优）和测试集（最终性能评估）。
2. 交叉验证：采用K折交叉验证，将数据分为K个子集，轮流用于训练和验证，提升评估的稳健性，避免过拟合。
3. 核心评估指标

   | 指标名称       | 公式/工具
   | 适用场景                                   |

|----------------|--------------------------------------------------------------------------|--------------------------------------------|

   | 准确率（Accuracy）
| Accuracy = (TP + TN)/(TP + TN + FP + FN)；可通过TensorFlow或Scikit-learn计算
| 分类问题默认指标，不适用于不平衡数据集     |

   | 精确率（Precision）
| 借助Scikit-learn或TensorFlow工具计算                                      | 需减少假阳性的场景（如垃圾邮件过滤）       |

   | 召回率（Recall）   | 借助Scikit-learn或TensorFlow工具计算                                      | 需减少假阴性的场景（如疾病诊断）           |

   | F1分数（F1-score）
| F1-score = 2×precision×recall/(precision + recall)                        | 综合衡量精确率和召回率，适用于多数分类场景
|

   | 混淆矩阵（Confusion
Matrix）
| 借助Scikit-learn工具或自定义函数实现                                      | 对比预测标签与真实标签，定位模型分类错误   |

4. ROC曲线下面积（AUC）：AUC值越接近1，模型性能越好；接近0.5时，模型接近随机猜测，无实际预测价值。

## 三、第二章强化学习

### 3.1 强化学习的定义

强化学习是除监督学习、无监督学习之外的第三类机器学习技术，核心是智能体（Agent）通过与环境的交互，在试错过程中学习最优策略，以最大化累积奖励。该学习方式无数据标签，唯一反馈来自奖励或惩罚信号，也可通过人类反馈引导智能体学习。

### 3.2 强化学习与监督/无监督学习的区别

| 学习类型       | 核心特征                 | 通俗类比                 |

|----------------|--------------------------|--------------------------|

| 监督学习       | 基于带标签数据，学习输入到输出的映射关系
| 从带标准答案的教材中学习
|

| 无监督学习     | 挖掘无标签数据的隐藏模式，识别数据分组特征
| 寻找有共同兴趣爱好的人群
|

| 强化学习       | 通过试错决策优化策略，依赖奖励/惩罚反馈
| 练习骑自行车，通过每次尝试不断改进
|

### 3.3 强化学习模型与工作流程

#### 3.3.1 核心模型

强化学习模型由智能体（Agent）、环境（Environment）、状态（St）、动作（At）和奖励（Rt）构成：智能体在当前状态St下执行动作At，环境会反馈奖励Rt，并切换到新状态S(t+1)，智能体的终极目标是最大化长期累积奖励。

#### 3.3.2 工作流程

1. 定义环境：智能体所处的物理或模拟场景。
2. 设定奖励机制：将奖励作为性能衡量标准，需多次迭代优化奖励规则。
3. 定义智能体与训练算法：根据环境和奖励需求，选择适配的智能体类型和训练算法。
4. 模型训练与验证：通过训练微调策略，此过程耗时耗资源。
5. 策略部署：确认最优策略后，投入实际应用。

### 3.4 强化学习典型应用场景

1. AlphaGo围棋对战：在与李世石的比赛中，AlphaGo通过强化学习走出了人类从未尝试过的“第37手”，展现发现全新解决方案的能力。
2. 雅达利游戏攻关：以原始游戏像素为输入，通过卷积神经网络和Q学习训练模型，最终性能超越人类专家玩家。
3. 自动驾驶：结合计算机视觉技术，车辆从初期的大幅转向，通过迭代训练逐渐实现平稳行驶，第11次训练后可无需人类干预自主行驶，且无需硬编码规则。
4. OpenAI Cartpole实验（强化学习“入门案例”）：智能体通过控制小车左右移动，防止车上的杆子倾倒；环境提供小车位置、速度及杆子角度等4个观测值，保持杆子直立即可获得奖励；任务在杆子倾倒、小车越界或达到200个时间步时结束。

### 3.5 强化学习的实现方式与核心算法

#### 3.5.1 实现方式分类

| 分类维度       | 具体类型                 | 核心特点                 |

|----------------|--------------------------|--------------------------|

| 模型依赖       | 基于模型的方法           | 构建环境内部模型，预测未来状态和奖励，优化决策
|

|
| 无模型方法               | 无需构建环境模型，直接通过交互学习策略     |

| 学习目标       | 基于价值的方法           | 利用价值函数（如Q表）评估动作潜在奖励，选择最优动作
|

|
| 基于策略的方法           | 通过确定性策略最大化奖励，包含复杂策略搜索和神经网络策略
|

#### 3.5.2 核心算法

1. Q学习：无模型、异策略算法，通过学习动作的“质量”（Q值）最大化奖励，基于贪心策略从随机动作中学习。
2. 状态-动作-奖励-状态-动作（SARSA）：有模型、同策略算法，基于当前状态和动作开展强化学习过程。
3. 深度Q网络（DQN）：融合深度学习，用神经网络替代传统Q表，高效计算状态值。

### 3.6 关键策略与参数

#### 3.6.1 探索与利用策略

- 探索：尝试新动作，获取环境和动作-奖励关系的更多信息，降低不确定性。
- 利用：基于已有知识选择当前最优动作，最大化即时奖励。
- ε-贪心策略：以概率ε随机探索，以概率1-ε选择当前最优动作，平衡探索与利用。
- 贪心算法：仅选择局部最优动作，计算高效但可能无法获得全局最优解。

#### 3.6.2 折扣因子γ

折扣因子取值范围为0-1，用于平衡即时奖励与未来奖励：γ值越高，智能体越重视未来奖励；γ值越低，智能体越倾向于获取即时奖励。核心公式为：Q
= 旧值

+ α×(r + γ×maxQ(s+1,a) - 旧值)（α为学习率）。

#### 3.6.3 多臂老虎机问题

- 问题描述：赌徒需选择多个老虎机中的一个进行游戏，每个老虎机的赔付率未知，目标是最大化总收益。
- 解决策略：采用ε-贪心策略，同时通过公式Q(a)
  = Q(a) + [1/N(a)]×(R - Q(a))更新动作价值（Q(a)为动作a的估计价值，N(a)为动作a的选择次数，R为获得的奖励）。

### 3.7 基于人类反馈的强化学习（RLHF）

RLHF是优化人工智能模型的关键技术，广泛应用于大语言模型训练，核心是将人类反馈融入奖励函数，使模型输出贴合人类需求，分为三个步骤：

1. 有监督微调（SFT）：收集人类生成的提示词-回复数据对，用于微调基础大语言模型。
2. 训练奖励模型（RM）：收集人类对模型多个回复的偏好数据，训练独立奖励模型，自动评估回复质量。
3. 策略优化：利用奖励模型优化模型策略，选择最可能获得高奖励的回复，确保输出无害、真实且符合人类价值观。

### 3.8 强化学习的挑战与未来方向

#### 3.8.1 现存挑战

1. 样本效率低：需要大量环境交互才能学习有效策略。
2. 计算成本高：模型训练对硬件资源需求极高。
3. 稳定性与收敛性差：部分算法（如神经网络相关算法）易不稳定，难以实现收敛。
4. 伦理风险：在医疗、金融等敏感领域，可能产生意外后果。

#### 3.8.2 未来方向

1. 深度强化学习：结合神经网络，提升智能体对数据细节的感知能力。
2. 迁移学习融合：让智能体将已有技能迁移到新领域，降低学习成本。
3. 多智能体强化学习：通过智能体间的交互，拓展应用场景。
4. 增强稳健性与泛化能力：提升智能体学习多样化技能的能力，推动强化学习的广泛应用。

### 3.9 进阶算法：分组相对策略优化（GRPO）

该算法旨在最大化目标函数，核心涉及样本分组、概率比率裁剪和正则化项等要素：通过控制概率比率范围（若概率比率过远偏离1则裁剪）和调整KL散度项权重，优化模型性能。公式中G为组内样本数，ε为小正数（<1），β为KL散度项权重。

## 四、第三章深度学习

### 4.1 深度学习的定义与核心特征

深度学习起源于模仿大脑工作机制的算法，是机器学习的子集，通过人工神经网络从大规模数据中学习。核心特征：

1. 无需硬编码特征，模型可自动学习特征。
2. 能学习多层抽象特征，将低级特征组合成高级模式。
3. 数据通过多层网络流动，最终输出结果。
4. 适配大数据场景，需依托大量计算资源（GPU/TPU）。
5. 于20世纪80年代开始应用，21世纪00年代后重新兴起并快速发展。

### 4.2 深度学习与机器学习的区别

| 对比维度       | 机器学习                 | 深度学习                 |

|----------------|--------------------------|--------------------------|

| 特征提取       | 需人工进行特征工程       | 自动学习特征             |

| 复杂度         | 擅长处理简单问题         | 擅长处理计算机视觉、自然语言处理等复杂任务
|

| 数据需求       | 需较小规模数据集         | 依赖大规模数据集         |

| 计算资源       | 可在CPU上运行            | 通常需GPU/TPU支持        |

### 4.3 深度学习的兴起原因

深度学习的重新崛起核心得益于数据量的爆发式增长：随着数据规模扩大，深度神经网络的性能远超浅层神经网络和传统机器学习算法，数据量的充足为深度学习模型的训练和优化提供了坚实基础。

### 4.4 深度学习的核心构建模块

#### 4.4.1 人工神经元与生物神经元对比

- 生物神经元：树突接收信号，胞体处理信号，轴突传递信号。
- 人工神经元：输入数据x通过突触权重w传递，经求和函数计算后，由激活函数输出结果y（z为突触总输入，f为激活函数）。

#### 4.4.2 正向传播与反向传播

| 对比维度       | 正向传播（Forward
Propagation）
| 反向传播（Backward
Propagation）
|

|----------------|----------------------------------|----------------------------------|

| 用途           | 计算预测结果                     | 更新权重和偏置                   |

| 传播方向       | 输入层→输出层                   | 输出层→输入层                   |

| 应用阶段       | 训练阶段和推理阶段               | 仅训练阶段                       |

| 数学操作       | 矩阵乘法、激活函数计算           | 基于链式法则计算梯度             |

| 核心目的       | 训练时获取损失值，推理时输出最终结果
| 调整参数以减少预测误差           |

### 4.5 关键优化技术

#### 4.5.1 梯度下降

梯度下降是优化神经网络参数的核心算法，用于寻找使代价函数最小化的权重w和偏置b：从初始参数点出发，逐步沿梯度方向迭代移动，最终逼近最优参数值，实现模型收敛。

#### 4.5.2 激活函数

激活函数的核心作用是为神经网络引入非线性（若缺少激活函数，无论网络有多少层，都仅等价于简单线性模型），同时助力特征学习和梯度传播。常见激活函数包括：Sigmoid函数、双曲正切函数（tanh）、ReLU函数、Leaky
ReLU函数、Maxout函数、ELU函数等。

#### 4.5.3 学习率选择

学习率α直接影响模型训练效果：

- 过小：需多次迭代才能逼近最优值，训练效率极低。
- 适中：快速收敛到最优参数点，训练效果最佳。
- 过大：参数更新幅度过大，导致模型发散，无法收敛。

### 4.6 神经网络的预测机制与全连接层

#### 4.6.1 预测原理

神经网络需先通过大规模数据训练（部分模型为预训练模型，如ChatGPT）；训练完成后，可对新数据进行预测，既适用于年龄、收入等连续值的回归任务，也适用于类别标签等离散值的分类任务。

#### 4.6.2 全连接层（Dense Layers）

全连接层是神经网络的关键组成部分，核心作用：

1. 特征组合与提取：将高级抽象特征转化为适配预测的形式。
2. 决策与输出：通过Softmax函数生成概率化分类结果。
3. 引入非线性：借助激活函数学习复杂关系。
4. 控制过拟合：可通过丢弃法（Dropout）、L2正则化等技术实现。

### 4.7 主流深度学习架构

#### 4.7.1 卷积神经网络（CNN）

卷积神经网络是计算机视觉任务的核心架构，典型结构包括：卷积层、ReLU激活函数、最大池化层和全连接层。以28×28×1的图像输入为例，经5×5卷积核卷积、2×2最大池化等操作后，将特征展平，输入全连接层输出结果，适用于图像识别等任务。

#### 4.7.2 Transformer架构

Transformer架构基于自注意力机制，彻底改变了自然语言处理领域，核心由编码器和解码器组成：输入序列经嵌入层和位置编码后，通过多头注意力机制、归一化和多层感知机（MLPs）处理，最终输出概率结果。该架构能捕捉序列中词语的长距离依赖关系，提升语义理解能力。

#### 4.7.3 自注意力机制

自注意力机制让模型能聚焦输入序列的关键信息，流程：

1. 输入表示：将每个词语转化为高维嵌入向量。
2. 构建矩阵：生成查询（Q）、键（K）和值（V）三个矩阵，用于计算词语间的关联。
3. 计算注意力分数：通过Q与K的点积计算相似度，缩放后经Softmax转化为概率。
4. 加权求和：将V与注意力分数相乘并求和，得到融合上下文信息的词语表示。

### 4.8 深度学习的应用场景

深度学习应用广泛，覆盖多个领域的核心需求：

1. 计算机视觉：目标检测、人脸识别等。
2. 自然语言处理：机器翻译、情感分析等。
3. 医疗健康：疾病诊断、药物研发等。
4. 自主系统：自动驾驶汽车、机器人等。
5. 金融领域：欺诈检测、算法交易等。
6. 其他场景：供应链优化、预测分析、推荐系统等。

### 4.9 深度学习的挑战与局限性

1. 数据要求高：需要大量高质量数据，数据不足会导致模型性能下降。
2. 计算成本高昂：对GPU/TPU等硬件资源需求大，训练成本高。
3. 可解释性差：模型具有“黑箱”特性，难以解释决策背后的逻辑。
4. 伦理风险：易受数据偏见影响，存在滥用和隐私泄露隐患。
5. 过拟合与泛化问题：模型易过度拟合训练数据，在新数据上表现不稳定。
